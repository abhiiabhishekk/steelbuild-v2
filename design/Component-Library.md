# Steelbuild V2 Component Library

## Buttons

### Primary Button
Used for main actions:
- Request a Quote
- Explore Projects
- Contact Us

Style:
- Red background
- White text
- 16px radius
- Bold typography
- Hover lift

### Secondary Button
Used for supporting actions:
- Learn More
- View Details

Style:
- Border
- Transparent background
- Hover fill

### Ghost Button
Used inside dark or image sections.

### Icon Button
Used for arrows, sliders and navigation controls.

---

## Cards

### Project Card

- Image
- Category
- Title
- Location
- CTA

### Industry Card
Used for industries served.

Includes:
- Background image
- Overlay
- Industry title
- CTA

### Feature Card
Used for benefits and why Steelbuild.

### Counter Card
Used for statistics.

### Testimonial Card
Used for customer validation.
